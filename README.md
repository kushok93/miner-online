# 💣 Сапёр-онлайн

Кооперативный сапёр для двоих прямо в браузере. Без очереди ходов — каждый открывает любые клетки когда хочет. Одна мина — проигрыш для обоих.

**Играть:** https://kushok93.github.io/miner-online/

## Как играть с другом

1. Открой ссылку выше — комната создаётся автоматически.
2. Нажми «Скопировать ссылку» и отправь другу.
3. Друг открывает ссылку и попадает на то же поле.

Курсор напарника виден как миноискатель его цвета: он «бипает», когда напарник открывает клетку или ставит флажок.

## Управление

- ЛКМ — открыть клетку
- ПКМ — поставить/снять флажок
- Клик по цифре (или колёсико) — открыть соседей, если флажков вокруг достаточно
- Телефон: тап — открыть, долгое нажатие или режим «🚩» — флажок

## Как устроено

Чистый JS без сборки: `game.js` — логика поля, `net.js` — P2P-связь через [PeerJS](https://peerjs.com/) (WebRTC), `app.js` — интерфейс.
Создатель комнаты хранит эталонное поле, действия гостя применяются у него и рассылаются обратно, поэтому одновременные клики не ломают синхронизацию. Сервер не нужен — сайт статический и живёт на GitHub Pages.

Локально: просто открой `index.html` в браузере.
